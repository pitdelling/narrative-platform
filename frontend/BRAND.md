# Arcane Editorial UI

The platform uses a warm, product-first visual system for narrative RPG tools.

## Principles

- 80% clear software, 15% editorial narrative, 5% arcane mystery.
- Information remains understandable when decoration is removed.
- Use symbols only when they communicate meaning.
- The default light theme is Linen, never pure white.
- Navy carries identity and primary actions; gold and copper are restrained accents.
- Serif typography represents authored narrative; sans-serif represents interface; monospace is reserved for technical metadata.

- Arcane Violet: `#7665A7`
- Cartographic Green: `#627A66`

## Typography

- Display and story prose: Cormorant Garamond.
- Interface: Source Sans 3.
- Technical metadata may use IBM Plex Mono in future modules.

## Product behavior

- Cards use subtle borders and shadows, not heavy frames.
- Only rare states such as canon integration use violet.
- Background celestial diagrams stay under 10% opacity.
- Mobile layouts remove most decorative elements before reducing content clarity.
