# Narrative Platform Web

Next.js application implementing the Arcane Editorial brand system and the first module, Arquivo do Cronista.

Copy `.env.example` to `.env.local`, set the backend URL, then use the npm scripts described in the root Portuguese setup guide.

## Navigation and account behavior

On screens up to 900px, the desktop sidebar becomes a hamburger drawer while a compact left rail keeps the party list, current archive and account one tap away. The account dialog displays the signed-in username and allows password changes. Game creation includes the opening fragment, and the game detail page puts the active composer before the protected thread.
